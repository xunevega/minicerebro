# Criterio editorial de Editados

Qué está bien y qué está mal cuando Editados toca un texto. Lo decide el autor;
el código y las instrucciones al modelo lo aplican. Si un resultado discute este
criterio, se cambia este documento primero y el código después.

## Corregir

Corrige errores de norma (RAE/ASALE) sin tocar el estilo.

- Corrige: ortografía, puntuación, concordancia, régimen, dequeísmo y queísmo,
  leísmo, laísmo y loísmo, subordinadas mal construidas, impropiedades léxicas.
- Una forma admitida por la norma no es un error, aunque haya otra preferible.
- Respeta la forma del autor: una frase larga sale larga y bien construida.
- En un texto correcto, no cambia nada.

## Editar

| Intensidad | Objetivo |
|---|---|
| Baja (0–399) | Retoque: pulir sin reescribir. Si el texto está bien, cambia muy poco. |
| Media (400–749) | Aclarar y simplificar. La simplificación debe notarse. |
| Alta (750–1000) | Reescritura con impacto: arranques, cierres, frases más rotundas, ritmo. |

Criterio común a cualquier intensidad:

- **Recortar:** solo redundancias. Nunca información ni matices de sentido
  (agentes, cronología, atribuciones, tiempo verbal de una idea ajena).
- **Recursos expresivos:** puede quitarlos o transformarlos si la frase gana.
- **Léxico:** puede pulirlo libremente.
- **Norma:** nunca introduce errores.
- **Párrafos:** se conservan, salvo reorganización justificada en intensidad alta.
- **Contenido:** hechos, tesis, nombres, citas y grado de certeza se conservan.
